# Finanzas personales

Aplicación Android para llevar las finanzas personales: ingresos y gastos,
presupuestos por categoría, deudas y tarjetas de crédito, metas de ahorro,
ingresos programados, recordatorios y respaldo. Con interfaz completamente en
español.

**Gratis, sin anuncios, sin cuentas y sin internet**: toda la información se
guarda únicamente en tu teléfono.

## Descargar

**[Descargar la última versión (APK)](https://github.com/bit94/gb-finanzas/releases/latest)**

## Instalación

1. Abre la página de descargas en tu teléfono y baja el archivo `.apk` más reciente.
2. Ábrelo. Android pedirá permitir la instalación desde esta fuente (GitHub): actívalo solo para esta instalación.
3. Si el sistema avisa que la app no proviene de una tienda, toca «Instalar de todos modos». Es normal en instalaciones manuales.

Si ya tenías la app instalada, el archivo se instala **como actualización** y tus datos se conservan.

**Requisitos:** Android 7.0 (2016) o superior.

## Actualizaciones

Cuando se publique una versión nueva, descarga su APK y ábrelo: se actualiza
encima de la instalada sin perder información. Si prefieres actualizaciones
automáticas, puedes usar [Obtainium](https://github.com/ImranR98/Obtainium)
apuntando a este repositorio.

## Privacidad

La app no recopila ni transmite datos: sin analíticas, sin publicidad y sin
conexión de red. Detalles en la
[política de privacidad](https://bit94.github.io/gb-finanzas-politica/).

## Problemas y sugerencias

Si encuentras un error o quieres proponer una mejora, abre un
[issue](https://github.com/bit94/gb-finanzas/issues).
